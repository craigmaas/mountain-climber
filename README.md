# Greta's Project

This is Greta's project folder. Start here!

## How to work in this folder

- Open this folder in VS Code (File > Open Folder > `Git Repos/greta`).
- Talk to Claude about what you want to build. Describe it in plain words,
  like "I want a website about horses" or "make a guessing game I can play".
- Claude will create the files here. You can ask it to change anything.

## Ideas to get started

- A web page about something you love (HTML + CSS)
- A small game you can play in the browser
- A quiz or a story that changes depending on your choices
